# 🔐 Password & Account Risk Analyzer

## 📌 Project Overview

The Password & Account Risk Analyzer is a Python-based cybersecurity project designed to evaluate password strength and identify potential account security risks.

It analyzes password characteristics such as length, uppercase letters, lowercase letters, numbers, special characters, common weak passwords, repeated characters, and sequential patterns.

It also evaluates account security through an account security checklist and provides recommendations to improve security.

## 🎯 Project Objectives

- Analyze password strength.
- Identify common weak passwords.
- Detect repeated and sequential password patterns.
- Evaluate account security risks.
- Provide security recommendations.
- Promote password security awareness.

## ✨ Features

### 1. Password Strength Analysis
- Checks password length.
- Identifies uppercase and lowercase letters.
- Checks numbers and special characters.
- Detects common weak passwords.
- Identifies repeated characters.
- Detects sequential patterns.
- Displays password strength and security score.

### 2. Account Security Analysis
- Checks Multi-Factor Authentication (MFA).
- Identifies password reuse.
- Checks account recovery security.
- Calculates account risk level.
- Provides security recommendations.

### 3. Dashboard
- Interactive user interface.
- Password analysis results.
- Account security checklist.
- Security score visualization.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/Madhumathi168/Password-Account-Risk-Analyzer.git
```

### Step 2: Open the Project Folder

```bash
cd Password-Account-Risk-Analyzer
```

### Step 3: Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.
